## Acceptance criteria

1. No arguments exits zero, prints exactly 0 widgets plus newline, and leaves stderr empty.
2. One integer prints its value plus ' widgets' and newline with zero exit and empty stderr, including zero, positive, 1, and negative counts.
3. --json alone defaults to zero; --json before or after an integer works for positive and negative counts. Each valid JSON invocation exits zero, leaves stderr empty, and emits exactly one object with only widgets and an integer value. Whitespace is unrestricted.
4. Noninteger counts, unknown options, and extra positional arguments exit nonzero with a useful stderr error and no successful count output.
5. test_count.py provides useful dependency-free automated CLI tests for AC1–AC4, including JSON integer type and argument placement. Task Verify runs those tests and fails if required behavior is absent.
